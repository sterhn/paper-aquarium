# Запуск на Windows 11

## 1. Установить Node.js (один раз)

Скачай с [nodejs.org](https://nodejs.org/) версию **LTS**, запусти установщик
и нажимай «Next» до конца. Галочки можно не трогать.

Проверить: открой **Терминал** (правый клик по «Пуск» → «Терминал») и набери

```powershell
node --version
```

Должно ответить `v18…` или новее. Если пишет «не распознано» — закрой
терминал и открой заново; не помогло — перезагрузи компьютер.

## 2. Скачать проект

Если есть Git:

```powershell
git clone https://github.com/sterhn/paper-aquarium.git
cd paper-aquarium
```

Или на GitHub: «Code» → «Download ZIP», затем правый клик по архиву →
**«Извлечь все…»**. Запускать прямо изнутри ZIP нельзя — сначала распаковать.

Устанавливать ничего не нужно: `npm install` не требуется, зависимостей нет.

## 3. Запустить

**Проще всего:** дважды щёлкни `start.bat` в папке проекта. Откроется чёрное
окно с сервером, а через пару секунд — браузер с аквариумом.

**Или из терминала:** открой папку проекта в Проводнике, правый клик по пустому
месту → **«Открыть в терминале»**, и набери

```powershell
node server.js
```

Сервер напишет:

```
Аквариумы: http://localhost:8000/
С телефона (та же Wi-Fi сеть): http://192.168.1.42:8000/
```

Открой в браузере **http://localhost:8000**.

## 4. Телефон (съёмка раскраски)

Телефон должен быть в той же Wi-Fi сети, что и компьютер. Адрес для него —
вторая строка, которую напечатал сервер (или QR-код в меню аквариума).

При первом запуске Windows спросит про брандмауэр для Node.js — **разреши
доступ в частных сетях**. Если окно закрыли или телефон не открывает страницу:

1. «Параметры» → «Сеть и Интернет» → твоя Wi-Fi сеть → «Тип сетевого профиля» →
   **Частная**.
2. «Пуск» → «Брандмауэр Защитника Windows» → «Разрешение взаимодействия с
   приложением…» → «Изменить параметры» → у **Node.js JavaScript Runtime**
   поставить галочку «Частная».

## Остановить сервер

**Ctrl+C** в окне сервера или просто закрыть это окно.

## Где данные

Аквариумы лежат в папке `data\tanks\` внутри проекта и переживают перезапуск.
Чтобы перенести на другой компьютер — скопируй папку `data` целиком.

## Частые проблемы

**`node` не найден** — переоткрой терминал после установки Node.js; не помогло —
перезагрузи компьютер.

**«Порт 8000 уже занят»** — сервер уже запущен в другом окне (закрой его) или
порт держит другая программа. Тогда запусти на другом порту.

В PowerShell (обычный терминал Windows 11):

```powershell
$env:PORT=3000; node server.js
```

В старой командной строке (cmd):

```bat
set PORT=3000
node server.js
```

И открывай http://localhost:3000.

**Телефон не открывает страницу** — см. раздел «Телефон» выше: Wi-Fi одна и та
же, профиль сети «Частная», Node.js разрешён в брандмауэре. Если сервер
напечатал несколько адресов — пробуй тот, что начинается с `192.168.`.

**Антивирус ругается** — добавь папку проекта в исключения.
