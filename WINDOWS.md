# Запуск на Windows

## Что нужно установить

1. **Node.js 18+** — скачай с [nodejs.org](https://nodejs.org/) (кнопка «LTS»), запусти установщик, нажимай «Next» до конца.

2. Перезапусти командную строку после установки, чтобы `node` и `npm` стали доступны.

## Скачать проект

Если есть Git:
```
git clone https://github.com/sterhn/paper-aquarium.git
cd paper-aquarium
```

Или скачай ZIP с GitHub → кнопка «Code» → «Download ZIP», распакуй куда удобно.

## Запуск

Открой папку проекта в проводнике, зажми Shift и нажми правой кнопкой мыши на пустом месте → **«Открыть окно PowerShell здесь»** (или **«Открыть в терминале»** в Windows 11).

В терминале:
```
node server.js
```

Должна появиться строка вроде:
```
Listening on http://localhost:8000
```

Открой браузер и перейди по адресу: **http://localhost:8000**

## Остановить сервер

Нажми **Ctrl+C** в окне терминала.

## Папка с данными

Аквариумы сохраняются в папку `data/tanks/` рядом с проектом. При следующем запуске все созданные аквариумы будут на месте.

## Частые проблемы

**`node` не найден** — закрой и снова открой терминал после установки Node.js. Если не помогло, перезагрузи компьютер.

**Порт занят** — если `8000` уже используется, задай другой:
```
set PORT=3000 && node server.js
```
Тогда открывай http://localhost:3000

**Антивирус блокирует** — добавь папку проекта в исключения. Node.js иногда ложно срабатывает.
