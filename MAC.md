# Запуск на Mac

## 1. Установить Node.js (один раз)

Скачай с [nodejs.org](https://nodejs.org/) версию **LTS** (установщик `.pkg`),
открой его и нажимай «Продолжить» до конца. Если пользуешься Homebrew —
`brew install node` тоже подойдёт.

Проверить: открой **Терминал** (Cmd+Пробел → «Терминал») и набери

```bash
node --version
```

Должно ответить `v18…` или новее.

## 2. Скачать проект

На GitHub: «Code» → «Download ZIP». Safari сам распакует архив в «Загрузки» —
появится папка `paper-aquarium-main`.

Или через Git:

```bash
git clone https://github.com/sterhn/paper-aquarium.git
```

Устанавливать ничего не нужно: `npm install` не требуется.

## 3. Запустить

**Проще всего:** дважды щёлкни `start.command` в папке проекта. Откроется
окно Терминала с сервером, а через пару секунд — браузер с аквариумом.

**Первый раз macOS может не дать открыть файл** — он скачан из интернета,
а не из App Store:

- **macOS 15 (Sequoia) и новее:** после отказа открой «Системные настройки» →
  «Конфиденциальность и безопасность», внизу у строки про `start.command`
  нажми **«Всё равно открыть»** и подтверди.
- **macOS 14 и старше:** правый щелчок по `start.command` → **«Открыть»** →
  ещё раз «Открыть» в окне предупреждения.

Это нужно один раз, дальше файл открывается обычным двойным щелчком.

Если вместо запуска открывается текстовый редактор или пишет «нет прав» —
у файла потерялся признак запускаемого (так бывает с некоторыми
распаковщиками). Почини в Терминале:

```bash
chmod +x ~/Downloads/paper-aquarium-main/start.command
```

**Или без start.command:** в Терминале набери `cd ` (с пробелом), перетащи
папку проекта из Finder в окно Терминала, нажми Enter, потом

```bash
node server.js
```

Сервер напишет:

```
Аквариумы: http://localhost:8000/
С телефона (та же Wi-Fi сеть): http://192.168.1.42:8000/
```

Открой в браузере **http://localhost:8000**.

## 4. Телефон (съёмка раскраски)

Телефон — в той же Wi-Fi сети, что и Mac. Адрес для него — вторая строка,
которую напечатал сервер (или QR-код в меню аквариума).

Если macOS спросит, разрешить ли программе **node** принимать входящие
подключения, — нажми **«Разрешить»**. Если окно закрыли, а телефон не
открывает страницу: «Системные настройки» → «Сеть» → «Брандмауэр» →
«Параметры» — у **node** должно стоять «Разрешать входящие подключения».

## Остановить сервер

**Ctrl+C** в окне Терминала (именно Ctrl, не Cmd) или просто закрыть окно.

## Где данные

Аквариумы лежат в папке `data/tanks/` внутри проекта и переживают перезапуск.
Чтобы перенести на другой компьютер — скопируй папку `data` целиком.

## Частые проблемы

**«Node.js не найден»** — установи Node.js (шаг 1) и запусти `start.command`
снова. Если ставил через Homebrew и всё равно не находится — открой Терминал
и проверь `which node`.

**«Порт 8000 уже занят»** — сервер уже запущен в другом окне (закрой его)
или порт держит другая программа. Тогда запусти на другом порту:

```bash
PORT=3000 node server.js
```

И открывай http://localhost:3000.

**Телефон не открывает страницу** — Wi-Fi одна и та же, node разрешён
в брандмауэре (раздел «Телефон» выше). Если сервер напечатал несколько
адресов — пробуй тот, что начинается с `192.168.`.
